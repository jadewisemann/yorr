# 족보 콜아웃 녹음 원본

녹음한 파일을 **이 폴더에** 아래 이름으로 넣고, `frontend/`에서 한 줄 실행하면
게임 에셋(`public/audio/hand-voice/*.wav`)이 만들어진다.

```bash
node scripts/import-hand-voice.mjs
```

> 이 폴더의 녹음 원본은 `.gitignore` 대상이다 — **변환 결과 wav를 커밋해야** 다른 기기로 넘어간다.
> 원본만 넣어두고 push하면 아무것도 전달되지 않는다.

## 처음 실행하는 기기라면

변환은 Chromium의 Web Audio(`decodeAudioData`)를 디코더로 쓴다. 그 기기에 브라우저가
없으면 첫 실행에서 실패하므로 한 번만 받아두면 된다.

```bash
npm ci
npx playwright install chromium
```

macOS에서는 음성 메모·QuickTime 녹음(`.m4a`)을 그대로 이 폴더에 넣으면 된다 —
변환 스크립트가 포맷·샘플레이트·채널을 알아서 맞춘다.

## 파일 이름

확장자는 무엇이든 된다 — 폰 음성메모(`.m4a`), 브라우저 녹음(`.webm`), Audacity(`.wav` · `.mp3`)
모두 그대로 받는다. **이름(확장자 앞부분)만** 아래와 정확히 같으면 된다.

| 파일 이름 | 읽을 말 | 화면 표기 | 콜아웃 표시 시간 | 에코 꼬리 | 말하는 시간 |
|---|---|---|---|---|---|
| `yacht` | 요트! | 요트!!! | 2.4초 | 0.54초 | 1.6초 이내 |
| `large-straight` | 라지 스트레이트! | 라지 스트레이트!! | 1.8초 | 0.45초 | 1.1초 이내 |
| `small-straight` | 스몰 스트레이트! | 스몰 스트레이트! | 1.4초 | 0.24초 | **0.9초 이내** |
| `full-house` | 풀하우스! | 풀하우스! | 1.4초 | 0.24초 | 0.9초 이내 |
| `four-of-a-kind` | 포커! | 포커! | 1.4초 | 0.24초 | 0.9초 이내 |

콜아웃 표시 시간은 족보 등급마다 다르다(`RollResultCallout.tsx`의 `tierByHand` ×
`durationMsByTier`). **목소리가 그보다 길면 텍스트가 먼저 사라진다** — 스크립트가
족보별로 검사해서 경고한다.

"말하는 시간"은 **파일 길이가 아니라 실제로 소리가 나는 구간**이다. 앞뒤 여유는 스크립트가
잘라내므로 녹음 파일이 2~3초여도 상관없다. 평소 속도로 한 번 지르면 0.5~0.9초면 끝나서
어느 족보든 여유 있게 들어온다 — 표는 넘치면 경고가 뜨는 상한이라고 보면 된다.

화면에는 등급만큼 느낌표가 붙지만, **말은 한 번만** 하면 된다(느낌표는 시각 연출이다).
"포카드"가 아니라 **"포커"** 인 이유는 점수판 라벨이 포커라서다 — 라벨을 바꾸려면
`src/yachtCategoryView.ts`의 `categoryLabel`과 함께 바꿔야 한다.

## 녹음 팁

- **한 파일에 한 줄만.** 여러 줄을 몰아 넣으면 하나로 붙어버린다.
- 앞뒤로 **0.5초쯤 여유**를 두고 녹음한다. 녹음 버튼 탭 소리·숨까지 스크립트가 잘라낸다.
- 마이크에서 **20~30cm** 떨어져서, 씩씩하게. 너무 가까이서 지르면 찌그러진다(클리핑).
- 조용한 곳에서. 배경 잡음이 말소리의 10%를 넘으면 경고한다.
- 볼륨은 신경 쓰지 않아도 된다 — 5개의 **체감 크기**를 같게 맞춰준다(피크가 아니라 RMS 기준).
- 길이는 거의 신경 쓸 일이 없다. 위 표를 넘기면 스크립트가 어떤 족보가 얼마나 넘쳤는지 알려준다.

## 스크립트가 해주는 일

디코드 → 22.05kHz 모노 → DC offset 제거 → **말소리 구간만 잘라내기** → **에코** →
페이드(앞 5ms · 뒤 40ms) → **체감 크기 정규화 + 리미터**.

에코는 `ECHO` 상수에 족보별로 적고, **값이 등급을 따라간다** — 화면 느낌표가 등급만큼
붙는 것과 같은 이유로 등급이 높을수록 길고 진하게 준다.

| 등급 | 족보 | 에코 | 꼬리 | 결과 |
|---|---|---|---|---|
| 3 | 요트 | `180ms x3 decay 0.50` | 540ms | 561 → 1101ms |
| 2 | 라지 스트레이트 | `150ms x3 decay 0.45` | 450ms | 882 → 1332ms |
| 1 | 스몰 스트레이트 | `120ms x2 decay 0.40` | 240ms | 842 → 1082ms |
| 1 | 풀하우스 | `120ms x2 decay 0.40` | 240ms | 731 → 971ms |
| 1 | 포커 | `120ms x2 decay 0.40` | 240ms | 561 → 801ms |

꼬리 길이는 `delayMs × repeats`로 정해진다. 그래서 위 표의 "말하는 시간"은 콜아웃 표시
시간에서 꼬리와 여유 200ms를 뺀 값이다 — 1등급이 0.9초로 가장 빡빡하다. 울림을 더/덜
주려면 `repeats`(꼬리 길이)와 `decay`(잔향 크기)를 조절하고, 꼬리를 늘렸으면 그만큼
빠르게 녹음해야 한다. 넘치면 스크립트가 어떤 족보가 얼마나 넘쳤는지 알려준다.

정규화는 피크가 아니라 **가장 큰 50ms 창의 RMS**를 맞춘다. 피크로 맞추면 뾰족한 순간 하나가
전체를 눌러버려서, 실제로 "라지 스트레이트"가 다른 파일과 피크는 같은데 체감은 6dB 작았다
(0.5를 넘는 샘플이 전체의 0.16%뿐이었다). 그 뾰족한 부분만 리미터로 눕히고 나머지를 올린다.
리미터가 샘플의 5%를 넘게 물면 소리가 뭉개질 수 있어 경고한다.

트림은 무음을 자르는 게 아니라 **말소리를 찾아서 그 구간만 남긴다.** 10ms 창의 RMS를 만들어
가장 큰 창의 15%를 넘는 구간을 말소리로 잡고, 음절 사이 0.25초 이내의 쉼은 이어 붙이고,
자음 꼬리만큼(최대 80ms)만 밖으로 넓힌다. 폰 녹음에는 녹음 버튼 탭·숨·방 잡음이 말소리의
5~12% 세기로 앞뒤에 붙어 있어서, 단순 무음 트림으로는 2초 넘는 파일이 그대로 남는다.

말끝이 잘릴 걱정은 하지 않아도 된다 — 검출 구간 밖에 말소리급(15% 이상) 소리가 남아 있으면
몇 ms 지점인지 찍어서 "들어보고 확인하라"고 경고한다.

결과만 커밋하면 되고, 이 폴더의 원본 녹음은 `.gitignore` 대상이라 저장소에 올라가지 않는다.
