# 족보 콜아웃 녹음 원본 (S15P11A406-138)

녹음한 파일을 **이 폴더에** 아래 이름으로 넣고, `frontend/`에서 한 줄 실행하면
게임 에셋(`public/audio/hand-voice/*.wav`)이 만들어진다.

```bash
node scripts/import-hand-voice.mjs
```

## 파일 이름

확장자는 무엇이든 된다 — 폰 음성메모(`.m4a`), 브라우저 녹음(`.webm`), Audacity(`.wav` · `.mp3`)
모두 그대로 받는다. **이름(확장자 앞부분)만** 아래와 정확히 같으면 된다.

| 파일 이름 | 읽을 말 | 화면 표기 | 콜아웃 표시 시간 | 권장 녹음 길이 |
|---|---|---|---|---|
| `yacht` | 요트! | 요트!!! | 2.4초 | 2.0초 이내 |
| `large-straight` | 라지 스트레이트! | 라지 스트레이트!! | 1.8초 | 1.6초 이내 |
| `small-straight` | 스몰 스트레이트! | 스몰 스트레이트! | 1.4초 | **1.2초 이내** |
| `full-house` | 풀하우스! | 풀하우스! | 1.4초 | 1.2초 이내 |
| `four-of-a-kind` | 포커! | 포커! | 1.4초 | 1.2초 이내 |

콜아웃 표시 시간은 족보 등급마다 다르다(`RollResultCallout.tsx`의 `tierByHand` ×
`durationMsByTier`). **목소리가 그보다 길면 텍스트가 먼저 사라진다** — 스크립트가
족보별로 검사해서 경고한다.

특히 `small-straight`가 빡빡하다. 문구는 제일 긴데(7음절) 등급이 낮아 창이 제일 좁으니
또박또박 대신 "스몰스트레이트!"처럼 붙여서 빠르게 말해야 1.2초에 들어온다.

화면에는 등급만큼 느낌표가 붙지만, **말은 한 번만** 하면 된다(느낌표는 시각 연출이다).
"포카드"가 아니라 **"포커"** 인 이유는 점수판 라벨이 포커라서다 — 라벨을 바꾸려면
`src/yachtCategoryView.ts`의 `categoryLabel`과 함께 바꿔야 한다.

## 녹음 팁

- **한 파일에 한 줄만.** 여러 줄을 몰아 넣으면 하나로 붙어버린다.
- 앞뒤로 **0.5초쯤 여유**를 두고 녹음한다. 무음은 스크립트가 알아서 잘라낸다.
- 마이크에서 **20~30cm** 떨어져서, 씩씩하게. 너무 가까이서 지르면 찌그러진다(클리핑).
- 조용한 곳에서. 배경 잡음이 크면 스크립트가 경고하고, 앞뒤 무음이 깔끔하게 안 잘린다.
- 볼륨은 신경 쓰지 않아도 된다 — 5개를 같은 크기(피크 -1dB)로 맞춰준다.
- 길이는 위 표의 "권장 녹음 길이"를 지킨다. 하나로 외우려면 **1.2초**가 안전선이다
  (요트·라지만 더 여유가 있다).

## 스크립트가 해주는 일

디코드 → 22.05kHz 모노 → DC offset 제거 → 앞뒤 무음 트림 → 5ms 페이드 → 피크 정규화.
결과만 커밋하면 되고, 이 폴더의 원본 녹음은 `.gitignore` 대상이라 저장소에 올라가지 않는다.
