# YORR Frontend — Claude Code 작업 지침

> `frontend/` 안에서 작업할 때는 [`AGENTS.md`](AGENTS.md)를 읽고 그대로 따른다.
> 그 파일이 이 디렉터리 작업 방식의 정본이며, 여기서 내용을 반복하지 않는다.

- 설계의 정본은 [`DESIGN.md`](DESIGN.md)다. 코드를 뒤지기 전에 먼저 읽는다.
- 진행 중 변경 계획(와이어 계약 동결 포함)은 [`PLANS.md`](PLANS.md)에 있다.
  **스타일·디자인 시스템 작업을 이어받는다면 PLANS.md의 "디자인 시스템" 절을
  먼저 읽는다** — 어디까지 왔고 무엇이 남았는지, 열린 결정과 검증 수단의 구멍이
  거기에 있다.
- Git 브랜치·커밋·PR 규칙은 루트 [`../CLAUDE.md`](../CLAUDE.md) ·
  [`../CONTRIBUTING.md`](../CONTRIBUTING.md)를 그대로 따른다.
