# YORR 프론트엔드 LLM 위키

이 폴더는 프론트엔드의 **하위 시스템 설계 문서** 층이다(백엔드 `docs/design/`에
대응). 문서 지도와 읽기 순서, 작성 규약은 [`../../DESIGN.md`](../../DESIGN.md)로
옮겼다 — **거기서 출발한다.** 에이전트 작업 프로토콜은
[`../../AGENTS.md`](../../AGENTS.md).

페이지마다 상단에 SSOT 코드 경로가 달려 있어 코드와 대조해 검증할 수 있다.
문서와 코드가 어긋나면 AGENTS.md의 판정 절차를 따른다 — 어긋난 채로 남겨두지
않는다. (2026-08-14 전까지는 "코드가 이긴다" 규칙이었다 — 전환 배경은
[`../adr/0001-design-doc-authority.md`](../adr/0001-design-doc-authority.md).)
