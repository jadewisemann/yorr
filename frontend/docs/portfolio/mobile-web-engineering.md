## 1. 모션 제스처 인식기를 직접 만들었다

흔들기·던지기를 판정하는 상태기계(`calibrating → idle → shakeCandidate → shaking →
thrown → cooldown`)를 구현했다. 핵심:

- **기기별 캘리브레이션** — 첫 300ms 노이즈를 측정해 임계값을 노이즈 배수로 산출. 고정
  임계값은 기기에 따라 오감지하거나 무반응한다.
- **히스테리시스 + 부호 반전 + 윈도 RMS**로 흔들기를, **축 우세 조건**으로 던지기를
  판정. 원시 센서값은 서버로 보내지 않고 판정된 게임 이벤트만 보낸다.
- **iOS 버그 발견·수정**: iOS Safari는 가속도 부호 규약이 Chrome과 반대라, 양수 방향만
  보던 던지기 판정을 아이폰에서는 통과할 수 없었다 — "던지기의 본질은 방향이 아니라 한
  축을 따라 날카롭게"로 재정의해 절댓값 판정으로 고쳤다.
- **중력 오염 보정**: `accelerationIncludingGravity` 폴백 기기에서 중력을 저역통과로
  빼지 않으면 임계값 14가 실질 4가 되어 오감지한다.
- **튜닝 도구까지 만들었다**: `/__dev/motion` — 실기기 임계값 슬라이더 + 센서 스트림
  **녹화/재생**(다른 설정으로 결정론적 재판정). 배포 환경에도 열어 실기기 튜닝에 썼다.

## 2. iOS 정책과의 전투 (전부 실측 근거)

- **볼륨**: iOS는 `HTMLMediaElement.volume` 대입을 조용히 무시하는데 **값은 저장해서
  기능 탐지조차 속는다** — `createMediaElementSource → GainNode` 경유로 우회하고,
  AudioContext는 모든 제스처에서 `resume()`(한 번만 깨우면 재잠금 후 영영 무음).
- **오디오 언락**: iOS는 `<audio>` 요소마다 제스처 이력을 따로 기억한다 — 게임 화면에서
  요소를 만들면 화면을 만진 적 없는 **관전자**에게 소리가 통째로 빠졌다. 앱 부팅 시
  모듈 레벨에서 생성해 해결.
- **보이스 지연**: `<audio>`는 play()마다 미디어 파이프라인을 재구축해 족보 보이스가
  0.6~0.8초 늦었다 — Web Audio 사전 디코딩으로 전환. 잠긴 컨텍스트는 iOS가 `interrupted`
  상태로도 두므로 `running`만 통과시킨다.
- **진동**: iOS 미지원 — 효과음·화면 연출로 대체하는 폴백 체계.
- **WebRTC**: 떼어놓은 `<audio>`는 iOS가 재생을 거부하는 경우가 있어 DOM에 부착.
- 센서 권한은 사용자 제스처 안에서만, 게임 시작 **전**(파티 대기실 사용법)에 끝낸다 —
  시작 직후 권한 팝업이 뜨면 첫 턴을 놓친다.

## 3. 입력 수단 간 공정성 — 지연을 설계로 보상

"석양이 진다"는 폰 스윙과 키보드가 같은 반응속도 게임에서 만난다:

- **입력별 페널티** `{swing: 0, key: 100, tap: 100}` — 팔을 휘두르는 시간과 손가락의
  차이를 실기기 튜닝 값으로 보상.
- **페널티는 숫자가 아니라 전송 지연으로 건다** — 신고값만 키우면 서버 clamp
  (`min(신고값, now - signalAt)`)가 깎아 회선이 빠른 쪽에서 페널티가 사라진다. 전송을
  늦추면 서버 기준 시각도 밀려 회선 무관하게 성립한다. 상한은 서버 유예 700ms.
- **반응 시간은 각자 자기 화면 기준** — 서버 도착 시각으로 재면 왕복 지연이 핸디캡이
  된다. 신호 기준 시각은 effect가 아니라 **첫 렌더에서** 잡는다(커밋과 effect 사이의
  아주 빠른 탭이 부정출발로 억울하게 신고되는 것 방지).
- **착탄 연출은 로컬 예측 + 지각 보정** — 총알 비행시간을 무대 폭 기반으로 계산(고정
  시간이면 폰에서 기어가고 노트북에서 순간이동), setTimeout 후 렌더+페인트 지각 45ms를
  실측으로 보정.

## 4. 좁은 화면 강건성

지원 하한 320px을 선언(`min-width: 320px`)하고 **E2E가 기하로 지킨다** — 스크린샷 비교
대신 가로 넘침을 숫자로 판정해 넘친 요소 이름까지 짚는 `narrow-width` 스펙 7개 +
전용 `mobile-320` Playwright 프로젝트. 한국어 어절 줄바꿈(`keep-all` + 안전망)은 전역
규칙으로 풀어 `<br>` 수동 고정을 없앴다.
