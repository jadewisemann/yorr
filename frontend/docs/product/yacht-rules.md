# 요트다이스 규칙

> 기준: [`../../src/domain/scoring.ts`](../../src/domain/scoring.ts). 규칙이 바뀌면 이 파일이
> 아니라 코드가 먼저 바뀐다 — 여기는 참고용 요약이다.

정규 요트다이스 12개 카테고리를 사용한다. **3 of a kind는 카테고리로 두지 않는다.**

## 상단(숫자)

`ones`, `twos`, `threes`, `fours`, `fives`, `sixes` — 해당 눈의 합.

- 상단 소계가 63점 이상이면 35점 보너스(`UPPER_BONUS_THRESHOLD = 63`,
  `UPPER_BONUS_POINTS = 35`).

## 하단(조합)

| 카테고리 | 점수 |
|---|---|
| `choice` | 다섯 주사위 총합 |
| `fourOfAKind` | 같은 눈 4개 이상이면 다섯 주사위 총합, 아니면 0 |
| `fullHouse` | 다섯 주사위 총합 |
| `smallStraight` | 연속 4개 — 15점 |
| `largeStraight` | 연속 5개 — 30점 |
| `yacht` | 같은 눈 5개 — 50점 |

## 공통 규칙

- 라운드당 최대 3회 굴림, 굴릴 때마다 원하는 주사위를 킵할 수 있다.
- 이미 사용한 카테고리는 재사용할 수 없다. 카테고리를 포기하면 그 카테고리는 사용 처리되고
  점수는 0이다.
- 클라이언트는 입력 반응을 위해 후보 점수를 로컬에서 계산하고, 서버는 제출된 족보의
  최종 점수를 다시 계산해 클라이언트 값을 신뢰하지 않는다.
