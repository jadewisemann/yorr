# 다빈치 코드 (DAVINCI_CODE)

> 프레임워크 공통은 [game-modules.md](../game-modules.md).
> min 2 / max 4 / supportsBots **false**. 라운드 프레임워크(RoundState·
> RoundTimerService)를 쓰지 않고 결투처럼 자체 상태기계 + 버전 키 스케줄링을 쓴다.

2~4인 추리 게임. 검정·흰색 0~11에 조커 두 장을 더한 스물여섯 장을 나눠 갖고, 자기
차례에 더미에서 한 장 뽑은 뒤 상대의 감춘 타일 하나를 지목해 숫자를 부른다. 맞히면 그
타일이 공개되고 한 번 더 부를지 고를 수 있으며, 틀리면 방금 뽑은 타일을 공개하고 턴을
넘긴다. 자기 타일이 전부 공개되면 탈락하고, 감춘 타일이 남은 사람이 하나면 이긴다.

## 구현 지도 (`src/game/davinci/`)

| 파일 | 책임 |
|---|---|
| `davinciState.ts` | 상태 타입 + **시점 투영**(`toView`) — 서버 상태와 와이어 타입이 다른 유일한 게임이다 |
| `davinciRules.ts` | 덱 구성·정렬 삽입·추측 판정·턴 전이·탈락·타임아웃 — **순수 함수** |
| `davinciStateStore.ts` | Redis 상태 저장(SETNX·락·TTL 복사·version 가드) — 결투 스토어와 같은 전략 |
| `davinciScoreboard.ts` | 종료 시 점수 기록 |
| `davinciGameService.ts` | 시각·난수 주입, **좌석별 전송**, 마감 예약, 종료 처리 |
| `davinciGameModule.ts` | WS 표면(`guess`·`decide`·`place` 라우팅·검증·오류 응답) |
| `davinciPorts.ts` | 바깥 계층(ws·room·완료)의 **좁은 포트** |
| `davinciSockets.ts` | 레지스트리 좌석 → 유니캐스트 어댑터 |

## 왜 방송하지 않는가 — 이 게임만의 전송 모양

결투·탁구·야추의 상태는 전부 공개 정보라 `RoomBroadcaster`가 방 전체에 **한 프레임**을
1회 직렬화해 뿌린다. 다빈치 코드에서 그렇게 하면 감춘 숫자가 모든 소켓에 실려, 개발자
도구를 연 사람이 판을 전부 알게 된다. 게임 자체가 사라지는 실패다.

그래서 서버가 `toView(state, viewerId)`로 좌석마다 숫자를 깎아 **유니캐스트**한다
(`DavinciAudience`). 좌석은 최대 넷이라 사람 수만큼 직렬화해도 부담이 없다.

- 남의 감춘 타일: `number = null`, 색과 공개 여부만 남는다.
- 내 타일과 이미 공개된 타일: 숫자가 그대로 실린다.
- 뽑아 든 타일(`drawn`): **색은 모두에게**, 숫자는 뽑은 사람에게만. 실제 게임에서 타일을
  자기 쪽으로 세워 드는 순간과 같은 비대칭이고, 그것이 다음 턴의 추론 재료다.
- 파티 대시보드는 `playerOrder`에 없으므로 감춘 숫자를 하나도 받지 않는다 — 관전 시점이
  따로 만들 것 없이 생긴다.

**판이 끝나면 숫자를 전부 연다.** 결과 화면의 값은 "누가 무엇을 끝까지 감췄는가"인데,
이긴 사람의 타일이 물음표로 남으면 진 사람은 자기가 무엇을 못 맞혔는지 영영 모른다.
단 `revealed` 플래그는 그대로 둔다 — 그 값이 점수의 재료(`맞힌 수 + 감춘 수`)라서,
함께 뒤집으면 이긴 사람의 점수가 끝나는 순간 0으로 무너진다.

이를 위해 `RoomSessionRegistry.membersOf(roomId)`를 더했다. 방 스냅샷의 플레이어 명단으로
대신할 수 없다 — 대시보드는 명단에 없지만 화면을 받아야 한다.

## WS 메시지 (접두사 `game.davinci_code.`)

- 인바운드 셋:
  - `guess {inputSeq:int, targetId:string, tileId:string, number:int}` — `number`는 0~11
    또는 `-1`(조커). 그 밖의 값은 `invalid_davinci_guess`.
  - `decide {inputSeq:int, decision:'CONTINUE'|'STOP'}` — 맞힌 뒤에만 유효하다.
  - `place {inputSeq:int, index:int}` — 조커를 넣을 자리(0 ~ 손패 길이).
- 아웃바운드: `game.davinci_code.state`(payload가 **그 좌석의 `DavinciView`**),
  `state.sync`(`{snapshot}` — 이탈·종료처럼 방 명단이 함께 움직일 때만 동봉),
  `game.davinci_code.game.over` + `state.sync`(완료 서비스).
- 무시되는 입력(내 차례 아님·이미 처리한 inputSeq·공개된 타일·탈락자 지목)은 상태를
  그대로 돌려주고, 스토어의 version 비증가 판정이 방송·재예약을 막는다(결투와 같은 관용).

## 상태

```
version(모든 변이마다 +1), phase(GUESSING|DECIDING|PLACING|FINISHED),
playerOrder[2..4], turnPlayerId, hands{playerId: Tile[]}, deck[], drawn|null,
turn, eliminated[], winnerId|null, hits{...}, lastInputSeq{...},
nextActionAt, lastEvent?
```

타일 id는 **섞은 뒤의 자리 번호**(`T0`~`T25`)다. `B7` 같은 식별자를 쓰면 감춘 타일의
id만 보고 답을 알 수 있다.

## 정식 규칙에서 손본 세 가지

1. **시작 패에 조커를 넣지 않는다.** 정식으로는 시작 패의 조커도 본인이 자리를 고르는데,
   그러려면 판이 시작하자마자 사람 수만큼 배치 단계를 거쳐야 한다. 조커를 더미에 남기면
   시작 패는 정렬만으로 결정되고, 조커의 자리 선택은 게임 중에 그대로 살아 있다.
2. **더미가 비었을 때 틀리면 가장 왼쪽 비공개 타일이 공개된다.** 정식으로는 공개할 타일을
   본인이 고르지만, 그 경우에만 쓰는 단계가 하나 더 필요하다. 26장 중 8~12장만 나눠 주므로
   실제로 닿기 드문 경로다.
3. **제한 시간이 있다**(추측 30초 · 선택/배치 15초). 정식 규칙에 없지만 실시간 방에서는 한
   사람이 멈추면 판이 통째로 멈춘다. 추측을 넘기면 **틀린 것과 같게** 처리한다 — 그러지
   않으면 아무 손해 없이 시간을 흘려 상대의 정보만 쌓게 할 수 있다.

## 정렬과 조커

손패는 왼쪽부터 오름차순, 같은 숫자면 검정이 왼쪽이다. 새 타일은 **규칙이 허용하는 가장
왼쪽** 자리에 들어간다(`insertIndexOf`). 조커는 어떤 숫자로도 통하므로 비교에서 건너뛰고,
그래서 조커 옆은 자리가 두 곳 이상 열리는데 그때마다 묻지 않고 왼쪽으로 붙인다 — 이미
놓인 조커가 흘리는 정보가 늘지 않기 때문이다.

조커를 손에 넣을 때만 `PLACING`으로 사람에게 자리를 묻는다. 공개된 조커(틀려서 공개하며
넣는 경우)도 마찬가지다 — 놓인 자리가 다음 추론의 재료라 공개 여부와 무관하다.

## 점수

**맞힌 타일 수 + 끝까지 감춘 타일 수.** 감춘 수만 쓰면 이긴 사람을 뺀 전원이 0점이라
3~4인 판의 2위와 4위를 구분할 수 없다. 결투와 같이 점수판 Lua(`CONFIRM_SCORE`)를 쓰지
않고 `room:{code}:scores` 해시에 정수 하나를 직접 쓴다 — 판정이 이미 끝난 값이다.

## 이탈

손패를 전부 공개하고 탈락시킨다. **자리를 `playerOrder`에서 지우지 않는다** — 남은 사람
화면에서 떠난 사람의 타일이 사라지면 그때까지 맞힌 기록도 함께 사라져 판을 되짚을 수
없다. 떠난 사람 차례였다면 곧바로 다음 사람에게 넘긴다.

## 불변식

- 서버 상태(`DavinciState`)는 **소켓으로 나가지 않는다.** 나가는 것은 언제나
  `toView`를 거친 `DavinciView`다.
- 규칙 함수는 상태를 바꿀 때만 `version`을 올린다. 무시할 입력에는 받은 상태를 그대로
  돌려준다.
- 마감(`nextActionAt`)은 상태 안의 절대 epoch ms다 — 프로세스가 죽었다 살아나도
  `rehydrate`가 같은 마감을 되살린다.
